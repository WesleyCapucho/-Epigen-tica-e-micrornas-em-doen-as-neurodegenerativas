# Database exports (not redistributed)

EN | The four Scopus and Web of Science export files that this review was built from are not redistributed in this repository or in its archived releases, because the terms of those databases limit redistribution. `../exports_manifest.csv` lists each file with its search date, record count and SHA-256 hash, so that a re-export can be compared with what was used. The records that were ingested, with their titles, abstracts and identifiers, are in `../screening_corpus.json` and `../additional_records_*.json`; the search strategies are in `../search_strategy.json` and `docs/en/HOW_TO_EXPORT_SCOPUS_WOS.md`. To run `scripts/09_ingest_scopus_wos.py` again, place a fresh export here (this folder is ignored by git apart from this note).

PT | Os quatro arquivos de exportacao do Scopus e da Web of Science de que esta revisao partiu nao sao redistribuidos neste repositorio nem nas versoes arquivadas dele, porque os termos dessas bases limitam a redistribuicao. `../exports_manifest.csv` lista cada arquivo com data da busca, numero de registros e hash SHA-256, para que uma nova exportacao possa ser comparada com a que foi usada. Os registros ingeridos, com titulos, resumos e identificadores, estao em `../screening_corpus.json` e `../additional_records_*.json`; as estrategias de busca estao em `../search_strategy.json` e `docs/pt-BR/COMO_EXPORTAR_SCOPUS_WOS.md`. Para rodar o `scripts/09_ingest_scopus_wos.py` de novo, coloque aqui uma exportacao nova (esta pasta e ignorada pelo git, exceto esta nota).
